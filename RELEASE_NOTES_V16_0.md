# GeoStats v16.0

This release restores no-scroll mobile gameplay, adds same-browser persistence for unsigned Daily results, removes legacy project naming, and moves Daily creation to an atomic pre-generation service.

The catalog now distinguishes raw coverage from ranking completeness. Sparse but defensible rankings can qualify as top-end complete, while incomplete lowest-wins rankings fail closed. Text similarity is a review warning rather than a hard conflict unless structured category metadata identifies the same gameplay strategy.

The release also repairs split-sheet Pew imports, changes Food Balance wording to “available per person,” retires World Heritage from active import, curates migration and technical World Bank categories, reconciles Natural Earth legacy rows, and introduces one v16 runtime/admin playability view.
