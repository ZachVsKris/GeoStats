# AnimalStats research database

## Verified state

The existing Supabase project now stores 68,579 private research records: the previous 56,900 plus 5,416 PanTHERIA rows and 6,263 COMBINE reported-data rows. These rows are pending research, not certified measurements or unique animal counts. The existing 4,673 gameplay catalog observations were not changed.

Four new private tables contain 162 comparison concepts, 322 proposed prize labels, 19 acquired catalog inventories with file hashes, and 1,296 pending quality checks. Opposites are linked for editorial review, not required together on game boards. The high/low endpoint keys distinguish the two labels; they do not imply that a larger numeric value always wins.

The reproducible SQLite snapshot has all 339,303 available normalized records across 19 catalogs, including study/specimen records and overlapping datasets. This count must not be presented as unique species, approved facts, or distinct measurements. The source inventory describes local acquisition; only seven raw catalogs are currently loaded in Supabase. No claim is made that all 19 are live.

## Quality control

Each concept has pending checks for source provenance, measured versus imputed values, units and definition, protocol comparability, uncertainty and ties, eligible animal coverage, broad interest, and rights. A keep recommendation is editorial interest only. This importer never approves gameplay data. Passing checks requires actual review; their creation is not a validation result. Promotion into the existing gameplay catalog remains a separate deliberate process.

Source payloads retain reported strings and missing sentinels verbatim, including -999 and NA, so the original record can be audited. These are not normalized numeric observations; missing sentinels must never be ranked. COMBINE's reported catalog still requires cell-level provenance checks; its name does not certify every value as directly measured.

Mammals may receive greater emphasis while boards retain animal/geographic variety and at least half intuitive comparisons. Restricted licenses and specialist traits remain research-only until cleared.

## Rebuild and queries

Run `python scripts/build-animalstats-research-db.py` after restoring the pinned source catalogs described in their manifests. This creates the ignored `AnimalStats_Research.sqlite` and live SQL seed files under `/tmp/animalstats-research-seed`. The SQLite database is a research tool, not bundled into the website. The raw third-party data are not republished in the repository.

Example SQLite queries:

```sql
SELECT bucket, interest, COUNT(*) FROM concepts GROUP BY bucket, interest;
SELECT c.id, p.label, c.recommendation FROM concepts c
JOIN prizes p ON p.concept_id=c.id ORDER BY c.id,p.endpoint;
SELECT catalog, COUNT(*) FROM research_records GROUP BY catalog;
SELECT json_extract(payload,'$.species'),
       json_extract(payload,'$.measurements.24-1_TeatNumber')
FROM research_records WHERE catalog='pantheria';
```

Live tables: `animal_research_concepts`, `animal_research_prizes`, `animal_research_sources`, `animal_research_checks`, and the existing `animal_research_records`. Existing approved catalog tables serve gameplay separately.

## Verification

SQLite integrity and foreign-key checks pass. A repeated build preserves record counts and pending status. Live counts match the import totals; all 1,296 quality checks are pending. Counter links have no broken pairs. New tables have RLS enabled and SELECT revoked from anon/authenticated roles. The security advisor reports informational no-policy notices for the deliberately private tables. Its separate existing leaked-password-protection warning is unrelated to this database change: https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection.

The migration was generated locally, then applied through the connected API. Automatic approval review blocked the CLI continuation because of telemetry; that step was replaced with the connected API and the work completed without further CLI execution.
