# GeoStats v16.0 installation

Use the full repository ZIP when replacing the current GitHub contents. The separate patch is only for a normal local Git checkout of the exact `GeoStats-main.zip` baseline used for this release.

## Installation order

1. In Supabase SQL Editor, run `RUN_THIS_IN_SUPABASE_FOR_V16_0.sql`.
2. Replace the GitHub repository contents with the v16.0 repository, preserving hidden folders such as `.github`.
3. Confirm the Vercel deployment succeeds.
4. In GitHub Actions, run **Import v16 automatic expansion**.
5. In Supabase SQL Editor, run `VERIFY_V16_0.sql`.
6. In GeoStats Admin, click **Generate Daily trio** if today's Scout, Adventurer, and Expert boards are missing. Future trios are generated by the scheduled v16 cron.

The v16 installer is rerunnable. Automated catalog finalization does not overwrite later administrator decisions because manually reviewed rows are protected by `reviewed_by`.

## Expected checks

- `category_review_overview_v16` exists and returns one consistent set of catalog counts.
- `publish_daily_trio_v16(date,jsonb)` and `refresh_v16_runtime_catalog()` are installed.
- Pew categories use 2020 and contain observations after the import workflow.
- Food Balance titles use “available per person.”
- World Heritage and UNESCO UIS are not playable or shown as active import sources.
- A complete Daily date has exactly three self-contained modes.

## Rollback

`ROLLBACK_V16_0.sql` restores the catalog fields captured before the first v16 installer run and removes v16 functions/views. It preserves historical Daily boards and scores.
