INSTALL
1. Upload this folder's contents to the GitHub repository root.
2. In Supabase SQL Editor, run RUN_THIS_IN_SUPABASE_FOR_V13_5.sql once.
3. Run VERIFY_V13_5.sql. Queries marked “must return zero rows” should be empty.
4. Follow AUTH_BRANDING_SETUP_V13_5.md.
5. Deploy through Vercel.
6. Test /daily, /daily/adventurer, /daily/expert, /random/easy, /random, and /random/expert.
